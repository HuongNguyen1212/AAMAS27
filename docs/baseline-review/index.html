Detailed instructions and examples

Your goal

Create one verified baseline for each question. Define every required schema field yourself from the question, reference answer and permitted source data. A baseline also contains grounded metadata values, exact source parts and procedures needed to reproduce the reference answer. You are not classifying failures on this page.

Before you start

  1. Enter a reviewer code, for example expert_01.
  2. Read the question and reference answer.
  3. Open the source files when you need to inspect them. Shared experiment information is background only.

What to select and what to type

Is the answer supported?
Use only the permitted source data listed for the question. Choose Yes when the source data supports every part of the reference answer. Choose Partially when it supports some parts but not all. Choose No when the required information is absent from the source data. Choose Not sure when you cannot determine support from the source data.
How the value was obtained
For each metadata value, choose whether you copied it, calculated it or interpreted the data. The final input box changes with this choice and tells you whether to enter a source location, calculation or scientific criterion.
Source files
Open the files to inspect their values. Select only the file or files actually used. Do not select every file unless all of them are needed.
Exact source parts
For every metadata value, tick the filename, header or data column that you used. A calculation must include every input column. A scientific interpretation must include every examined column.
Shared experiment information
This is provided only to help you understand the experiment. It is not an evidence source. Do not use it to verify the answer or enter a metadata value.
Define a schema field
For every required metadata value, enter a short concept name such as potential unit. The page converts it mechanically to potential_unit. Check the suggested name, choose its data type and write one sentence explaining what the field stores, including its scope and unit when needed. No pre-existing or model-generated schema fields are provided.
Value
Enter the value supported by the evidence, including the unit when the field is text. Do not invent a value to match the reference answer.
Direct reading
No formula. Use this form: Column or header = Potential applied (V).
Calculation
Use this form: Formula = max(Time(s)) - min(Time(s)); Input = Time(s); Unit = seconds.
Scientific rule
Use this form: Rule = ...; Threshold = ...; Data region = .... Write not applicable when no numerical threshold is used.

One short example

For “What is the total duration?”, define experiment_duration_seconds, enter 5400, choose Calculate, tick the Time(s) column and write Formula = max(Time(s)) - min(Time(s)); Input = Time(s); Unit = seconds.

For a potential unit, enter potential unit as the short concept name, check the suggested name potential_unit and describe it as Unit used for applied and working-electrode potential values.

If an answer needs two metadata values, such as potential unit and current unit, complete one value box for each field.

Finish and save

Select Check my entries. Read the summary and tick the four confirmation boxes. Then select Save this question and continue. Use Export Progress before changing computers and Import Progress to continue later.
