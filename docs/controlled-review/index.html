Worked example: how to judge one case

Schema and metadata in this review

Schema (section A) lists the fields available to the system. Each field states what can be stored and, when needed, how it can be read or calculated. A field or rule that is not shown is unavailable in that case.

Metadata (section B) lists the values and source-column references currently available from the source data. Metadata that is not shown is unavailable in that case.

The exact Schema JSON and Metadata JSON are provided under sections A and B of every case and can be expanded for verification.

If the source contains the required information but the schema has no suitable instruction for it, assess Missing capability (Schema Deficiency).

QuestionWhat is the maximum temperature?
Available source fileThe file contains a Temperature (°C) column.
A. Schema fields available to the systemThe schema has fields for time and length, but no field or calculation rule for maximum temperature.
B. Metadata available from the current source dataThe permitted source file contains the temperature column.
C. Answer producedNo answer.
D. Evaluator decisionThe answer was rejected.

How to decide

  1. The question requires the maximum temperature.
  2. The permitted source file contains temperature data, so the source information is not missing.
  3. Section A has no instruction for storing or calculating maximum temperature.
  4. The missing instruction explains why the system could not answer.
Missing capability (Schema Deficiency)Yes
Missing source information (Data Gap)No
Answer-use problem (Reasoning Failure)No
Wrong rejection (Evaluation Failure)No

The simplest way to distinguish the four causes

Check: Schema instructions → source/metadata → answer → rejection.

Cause Schema Source and metadata Answer Rejection
Schema Deficiency Required field or rule is missing Required source information is available May be “No answer” Rejecting the answer can be justified
Data Gap Required field and rule are available Required information is missing May be “No answer” Rejecting the answer can be justified
Reasoning Failure Required field and rule are available Required information is available Wrong, contradictory or missing Rejecting the answer can be justified
Evaluation Failure Required field and rule are available Required information is available Correct and supported Correct answer is rejected

Assess all four causes separately. Choose Yes only when the shown case satisfies the full row for that cause.

Choose Cannot decide when the page does not provide enough information to verify a condition. Do not choose Yes merely because C says “No answer.”
