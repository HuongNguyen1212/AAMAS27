Review guide
1. Read the question, shown schema fields, metadata, answer and evaluator feedback.
2. Judge each failure hypothesis independently from the shown evidence.
3. Use SUPPORTED only when the evidence positively supports that cause.
4. Use UNRESOLVED when the evidence is not enough to decide.
5. Cases selected for re-review start blank. Other cases retain the previous assessment and remain available for inspection.
6. Click Export Progress at any time. To continue on another computer, open this page and use Import Progress to restore the downloaded JSON.

Schema Deficiency

Can the schema represent what the question needs?

Supported when the schema lacks a required field, structure, unit, provenance, extraction rule or derivation rule.

Data Gap

Is the required information available from the permitted evidence?

Supported when the source evidence shown for this case cannot ground or derive the needed information.

Reasoning Failure

Was enough grounded metadata available but used incorrectly?

Supported when the answer ignores, misuses, miscalculates or contradicts available grounded metadata.

Evaluation Failure

Was a grounded answer rejected?

Supported when the answer is responsive and supported by shown evidence, but the evaluator feedback rejects it.
